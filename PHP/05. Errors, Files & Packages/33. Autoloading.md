# Autoloading

## TL;DR

Writing ten `require_once` lines at the top of every PHP file gets messy fast as your Book Tracker grows. **Autoloading** tells PHP how to find and load a class's `.php` file automatically the first time you use that class.

> [!NOTE] Prerequisites: 32
> New terms: autoloader, PSR-4

> [!abstract] Core Idea
> Register a callback with `spl_autoload_register()` that maps a class name (following **PSR-4** folder conventions) to its `.php` file path so PHP loads classes on demand.
> Like Python's `import` finding `.py` files by module path, **PSR-4** maps PHP namespaces directly to folders, except PHP runs a registered **autoloader** callback when an unknown class is first referenced.

## Mental Model

Think of an **autoloader** as a smart library runner. Instead of fetching every book from storage before you even sit down (`require_once`), you just ask for `new BookTracker\Models\Book()`, and the runner converts `BookTracker\Models\Book` into `src/Models/Book.php` and fetches it only when needed.

```mermaid
flowchart LR
    C["new BookTracker\Models\Book()"] -->|"Class not loaded yet"| A["spl_autoload_register() callback"]
    A -->|"Maps \ to / + .php"| F["require_once 'src/Models/Book.php'"]
    F --> R["Class Book is ready"]
```

- An **autoloader** is a function registered with `spl_autoload_register()` that PHP calls automatically whenever your code references a class, interface, trait, or enum that has not been loaded yet.

## Minimal Example

```php
<?php
spl_autoload_register(function (string $class): void {
    $prefix = 'BookTracker\\';
    if (!str_starts_with($class, $prefix)) {
        return;
    }

    $relative = substr($class, strlen($prefix));
    $file = __DIR__ . '/src/' . str_replace('\\', '/', $relative) . '.php';

    if (file_exists($file)) {
        require_once $file;
    }
});

// Now `new BookTracker\Models\Book('Dune')` loads src/Models/Book.php automatically
```

- `spl_autoload_register(...)` adds your callback to PHP's autoload queue (and can be called multiple times for multiple loaders).
- `$class` receives the full class name without a leading backslash (for example, `'BookTracker\Models\Book'`).
- `__DIR__` is a magic constant holding the directory path of the current PHP file.
- `str_replace('\\', '/', $relative)` turns namespace backslashes into folder slashes to build `src/Models/Book.php`.

## Compare

| Loading Style                  | When File Loads               | Boilerplate              | Best For                   |
| ------------------------------ | ----------------------------- | ------------------------ | -------------------------- |
| `require_once 'src/Book.php';` | Immediately, even if unused   | High (one line per file) | Small 1-2 file scripts     |
| `spl_autoload_register(...)`   | On demand, on first class use | Low (written once)       | Multi-file apps & packages |

## ◈ Edge Case Analysis

✗ **Mistake 1:** Expecting `spl_autoload_register()` to autoload standalone functions fails because PHP autoloaders only trigger for classes, interfaces, traits, and enums.

```php
// Autoloaders are NOT called when you call a missing standalone function:
formatBookTitle('dune'); // Fatal error: Call to undefined function
```

✓ **Fix:** Put reusable helpers in classes or load plain function files explicitly via `require_once` (or Composer's `"files"` autoloading).

```php
require_once __DIR__ . '/src/helpers.php';
```

✗ **Mistake 2:** Throwing an exception inside an autoloader callback stops any other registered autoloaders in the queue from running.

```php
spl_autoload_register(function (string $class): void {
    throw new RuntimeException('Missing!'); // Blocks later autoloaders
});
```

✓ **Fix:** Simply `return;` if `$file` does not exist so the next autoloader in the queue can try, and let PHP report `Class not found` if none succeed.

```php
if (file_exists($file)) {
    require_once $file;
}
```

✗ **Mistake 3:** Naming the file `book.php` when the class is `Book` works on Windows locally, then crashes on Linux servers where filenames are case-sensitive.

```text
// Class: BookTracker\Models\Book
// File:  src/Models/book.php  <-- Fails on Linux!
```

✓ **Fix:** Always match the exact uppercase/lowercase spelling of both the namespace folders and the class filename (`src/Models/Book.php`).

```text
// File: src/Models/Book.php
```

## Try It

1. If `$class` is `'BookTracker\Storage\Shelf'` and the base folder for `'BookTracker\'` is `__DIR__ . '/app/'`, what exact file path should a **PSR-4** autoloader build?
2. Write a minimal `spl_autoload_register()` callback that loads any class from `__DIR__ . '/classes/' . $class . '.php'` if that file exists.

<details>
<summary>◈ View Solution</summary>

1. Path built by PSR-4 mapping:

- Strip `'BookTracker\'` → `'Storage\Shelf'`
- Replace `\` with `/` and append `.php` → `__DIR__ . '/app/Storage/Shelf.php'`

2. Minimal autoloader callback:

```php
<?php
spl_autoload_register(function (string $class): void {
    $file = __DIR__ . '/classes/' . str_replace('\\', '/', $class) . '.php';
    if (file_exists($file)) {
        require_once $file;
    }
});
```

</details>

## Topic Mastery Quiz

**Q1: Which built-in function registers an autoloader callback in PHP 8.4?**

- [ ] A) `register_autoload()`
- [ ] B) `spl_autoload_register()`
- [ ] C) `require_autoload()`
- [ ] D) `__autoload()`

**Q2: Under PSR-4, if `BookTracker\` maps to `src/`, where should `BookTracker\Models\Book` live?**

- [ ] A) `src/BookTracker/Models/Book.php`
- [ ] B) `src/Models/Book.php`
- [ ] C) `src/Models/book.php`
- [ ] D) `BookTracker/src/Book.php`

**Q3: When does PHP call your registered autoloader?**

- [ ] A) At the start of the script for every `.php` file in the folder
- [ ] B) Only when your code references a class, interface, trait, or enum that is not loaded yet
- [ ] C) Every time you call `echo`
- [ ] D) Only when a syntax error occurs

**Q4: Which of these does PHP's autoloader NOT load automatically?**

- [ ] A) Classes
- [ ] B) Interfaces and traits
- [ ] C) Enums
- [ ] D) Standalone functions outside a class

**Q5: Why should an autoloader return quietly instead of throwing an exception when a file is not found?**

- [ ] A) Throwing an exception stops later autoloaders in the queue from getting a chance to load the class
- [ ] B) `throw` is forbidden inside callbacks
- [ ] C) PHP ignores exceptions in autoloaders
- [ ] D) `file_exists()` throws automatically

**Q6: Why does `src/Models/book.php` work on Windows but fail on a Linux server for `class Book`?**

- [ ] A) Linux does not support namespaces
- [ ] B) Linux filesystems are case-sensitive, so `Book.php` and `book.php` are different files
- [ ] C) Windows ignores `.php` extensions
- [ ] D) `spl_autoload_register()` only runs on Linux

<details>
<summary>◈ View Answers & Explanations</summary>

1. **B** — `spl_autoload_register()` is the standard function to register one or more autoloaders in PHP 8.4. `__autoload()` (D) was deprecated and removed in PHP 8.0, and A and C do not exist.
2. **B** — PSR-4 replaces the namespace prefix (`BookTracker\`) with the base directory (`src/`) and maps the remaining parts with matching case: `src/Models/Book.php`. A repeats the prefix, and C uses lowercase `book.php`.
3. **B** — Autoloading is lazy: PHP invokes the autoloader only when a class-like symbol (class, interface, trait, or enum) is first used and not yet defined. A, C, and D are false.
4. **D** — PHP's `spl_autoload_register()` only triggers for class-like symbols (classes, interfaces, traits, and enums), never standalone functions. A, B, and C are all autoloaded.
5. **A** — Multiple autoloaders can be queued; throwing an exception aborts the queue so remaining autoloaders cannot run. B, C, and D are false.
6. **B** — Windows filesystems are usually case-insensitive, while Linux filesystems are case-sensitive, so `Book.php` must match `class Book` exactly. A, C, and D are false.

</details>
